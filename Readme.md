=== Student Management System ===
- A simple command - line application built with Python managing student's records with Json files for data storage.

== Features ==
- Show Students: Display all students.
- Add Students: Add a student with name, age and grade.
- Remove Students: Remove a student by name.
- Filter Students: Find students based on minimum grade and minimum age then saving the file in Json folder.
- Analyze Students: Show average grade , highest grade, lowest grade, how many students passed (base grade = 10) and who is the student with the best grade. 

== Technologies == 
- Python 3
- Json
